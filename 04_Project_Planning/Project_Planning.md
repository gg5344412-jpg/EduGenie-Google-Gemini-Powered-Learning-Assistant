# PHASE 4 – PROJECT PLANNING

## EDU GENIE – GOOGLE GEMINI POWERED LEARNING ASSISTANT

---

## 1. Introduction

The Project Planning Phase defines how the EduGenie project will be developed, tested, documented, and demonstrated.

The project is divided into different phases so that each stage can be completed in an organized manner.

The major project phases are:

1. Brainstorming & Ideation
2. Requirement Analysis
3. Project Design
4. Project Planning
5. Project Development
6. Project Testing
7. Project Documentation
8. Project Demonstration

---

## 2. Project Planning Objectives

The main objectives of project planning are:

- To organize the project development process.
- To divide the project into manageable phases.
- To identify the required technologies and resources.
- To define project milestones.
- To plan development and testing activities.
- To ensure proper project documentation.
- To prepare the final project demonstration.
- To maintain the project phase-wise in GitHub.

---

## 3. Project Development Strategy

EduGenie is planned and developed using a phase-wise approach.

The development process starts with identifying the project idea and requirements. The requirements are then converted into a system design.

After designing the system, the application is developed using Python, FastAPI, HTML, CSS, JavaScript, Jinja2, and Google Gemini API.

The developed application is then tested using different functional test cases.

Finally, the project is documented and prepared for demonstration.

## 6. Development Planning

The development work is divided into the following activities:

### Activity 1 – Project Setup

The Python project environment is prepared and the required dependencies are installed.

### Activity 2 – Backend Development

The FastAPI application is created and configured.

### Activity 3 – Gemini API Integration

The Google Gemini API is integrated with the backend.

### Activity 4 – Q&A Module

The Question and Answer functionality is implemented.

### Activity 5 – Explanation Module

The concept explanation functionality is implemented.

### Activity 6 – Summary Module

The content summarization functionality is implemented.

### Activity 7 – Quiz Module

The quiz generation and answer validation functionality is implemented.

### Activity 8 – Learning Recommendation Module

The learning recommendation functionality is implemented.

### Activity 9 – Frontend Development

The user interface is created using HTML, CSS, and JavaScript.

### Activity 10 – Integration

The frontend and backend are connected through API requests.

### Activity 11 – Testing

All major application features are tested using different inputs.

### Activity 12 – Documentation

The project report and phase-wise documentation are prepared.

### Activity 13 – Demonstration

The completed application is prepared for final demonstration.

## 7. Project Milestones
